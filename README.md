# Node.js Runtime Notebook

게임 서버 개발자로서 Node.js의 실행 방식과 입출력을 이해하기 위한 개인 학습 저장소입니다.
Node.js 공식 Learn의 목차 순서를 따라 공부하고, 작은 프로그램의 예상과 실제 동작을 비교합니다.

## 학습 기준

- 순서: [Node.js 공식 Learn](https://nodejs.org/learn)의 사이드바.
- API 동작: 실행 중인 Node.js 버전과 일치하는 [공식 API 문서](https://nodejs.org/api/).
- 학습 기록: 원문, 내 설명, 실행 코드, 실제 출력, Codex Astra 활용과 판단 근거.

NestJS 학습 저장소와 독립적으로 운영합니다. 이 저장소의 예제는 Node.js 자체의 동작에 집중합니다.

## 학습 방향

1. 공식 Learn의 페이지를 순서대로 읽고 최소 예제를 실행합니다.
2. 의문이 생긴 API는 선택한 Node 버전의 문서를 확인합니다.
3. 원문 학습 뒤에는 타이머 지연, 파일 처리, 작업 분리 같은 작은 실험으로 확장합니다.

게임 서버와 관련한 질문도 기록하지만 처음부터 게임 전체를 만들지는 않습니다.
심화 실험은 원문 진도와 별도로 관리합니다.

## 계획한 구조

- notes/: 공식 Learn 목차별 내 설명과 실험 기록
- labs/: 해당 주제의 작은 실행 프로그램
- evidence/: 실행 환경·명령·실제 출력
- sessions/: 날짜별 학습과 AI 협업 기록
- references/: 원문 링크와 진도표
- docs/: 학습 운영 안내와 템플릿

첫 README 이후 필요한 파일부터 추가합니다. 아직 없는 파일은 구현 완료로 표시하지 않습니다.

## Codex Astra 활용

공식 원문을 읽고 내가 설명한 내용을 바탕으로 Astra에 질문, 반례 제안, 코드 리뷰, 오류 분석을 요청할 계획입니다.
세션마다 실제 모델 표시 이름, AI가 도운 부분, 내가 수행한 부분, 채택·수정한 이유와 실행 결과를 구분해 기록합니다.
실행하지 않은 예측과 실제 관찰 결과도 구분합니다.
